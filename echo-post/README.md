# 回声邮局 II · 指令与包裹

一款回合制时空合作解谜游戏。新版重做了八个关卡，围绕同一条关键规则展开：**回声重播方向指令，不是照搬过去的位置**。你改变门和箱子的状态，就能让昨天失败的动作在今天成功。

## 游玩

用现代浏览器打开 `回声邮局.html`，无需安装依赖。它包含全部代码、插画和样式，没有联网请求。也可以在本目录运行 `python3 -m http.server 4173`，访问 http://localhost:4173 。

第 1 关是箱子顺序题，第 2 关介绍门与回声，第 3～5 关探索操作回放与时机，第 6～8 关组合站位、机关和分拣顺序。底部编号可自由跳关；想直接体验新机制，可以从第 3 关开始。

## 三条规则

1. **推箱子**：把包裹推到所有绿色收货位，再到邮筒签收。箱子不能拉，也不能推入另一个箱子或角色所在的格子。有的关卡有多余箱子，可用它压机关。
2. **录指令**：空格保存本轮所有方向和等待操作，重置箱子、角色及时间。撞墙、撞门同样占用并记录一步。回声每回合按录制先后行动，随后轮到你；走完录像便停留。
3. **改变处境**：你打开门或挪动箱子后，回声的同一条操作可能产生不同结果。同字母机关须全部被角色或箱子压住；角色之间可以互相穿过。

箱子并不随录制永久保存。留影会把整个场景重置，所以实际解法必须考虑新一轮的初始状态。

## 操作与试错

| 操作 | 键盘 |
| --- | --- |
| 移动 / 推箱子 | 方向键、WASD |
| 留下回声 | Space |
| 等待一回合 | E |
| 撤销，包括推箱、留影和重试 | Z |
| 保留全部录像，重试本轮 | F |
| 删除最新一段录像并重试 | Q |
| 重置当前关卡全部内容 | R |

手机支持方向按钮与地图滑动。时间轴展示已执行指令和回声下一步；回声旁的小箭头也是下一条指令。每关有三级渐进提示。

## 三星与存档

- 一星：完成所有收货并签收。
- 二星：签收时同时收集纪念邮票。
- 三星：满足二星，并让“全部录像长度 + 最终行动长度”不超过关卡目标。

每关的星章和最少总操作保存在当前浏览器的 `echo-post-v2` 本地存档。旧版存档保留但不迁移，因为关卡和规则已经改变。撤销不会删除已获得的通关记录。文件地址、HTTP 地址、不同浏览器或隐私模式可能使用不同存档。

## 开发

零运行时依赖：原生 HTML、CSS、Canvas、Web Audio 和 JavaScript。

- `engine.js`：确定性规则引擎，纯状态转换，可在浏览器和 Node 中运行。
- `levels.js`：八个关卡、步数目标和分级提示。
- `game.js`：输入、撤销历史、存档、渲染、音效、时间轴。
- `assets/`：角色及包裹插画图集。
- `build.mjs`：生成单文件离线版。
- `tests/engine.test.cjs`：可达性与机制回归测试。包含通关路线，想自己解谜请暂时别看。

```sh
node --test tests/*.test.cjs
node build.mjs
```
